## 外观与照明近似

- 普通桌区地面按灰绿／浅鼠尾草色、有接缝及轻微使用痕迹的弹性地板外观处理；可近似为乙烯基地板着色器，但照片不能证明其实际材质类别。
- 舞台采用浅橡木色的方向性木纹；“橡木色”是外观描述，不是对实际木种的判断。墙面板、竖条和舞台踏面应具有不同的反光与纹理尺度。
- 幕布采用深酒红织物外观；依靠真实褶皱产生明暗变化，避免单张平面上的统一红色。
- 白色柜门可见较强反光，而白色椅背、桌腿、普通墙面与地板的反光相对柔和，应分设材质粗糙度。桌面边缘与椅背宜有圆角。
- 开灯时以顶面矩形面光源形成柔和阴影。照片中的冷暖色、亮度和高光受手机白平衡、曝光、拍摄方向影响，不能直接换算为现场灯具色温、流明或照度。
- 关灯后“几乎全黑”沿用用户的现场说明。照片 2 的相对明亮区域可能受门口光线或相机曝光影响，不能据此添加窗户、天空光或常亮环境照明。
- 幕布开合、灯光分区与暗适应是原型交互设计；实际开关面板数量、回路分区、幕布是否电动及暗适应时间均尚未得到照片确认。

## 继续沿用的空间关系

仍以用户已经确认的空间关系为准：无窗矩形地下教室；教学墙 → 小组桌 → 幕布 → 架高梯形舞台 → 后墙；舞台短边直接贴后墙，左右斜边旁为道具间。沿用已确认的整体镜像结果：面对舞台时三扇门位于左侧，后门进入左道具间。照片视角的左、右不应直接替代模型坐标的左、右。

每组六张等形梯形桌组成中空正六边形来自用户确认。照片支持桌面形状和颜色，但未完整展示所有桌组，因此当前参数里的 3 × 3 排布仅是工作假设，并非“实景共有九组”的结论。
