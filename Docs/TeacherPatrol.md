# 老师突击检查 / Teacher inspection

老师检查是一项可选的突发事件，覆盖漫游、“你寻找，NPC 躲藏”、“你躲藏，NPC 寻找”，以及两种角色的明亮练习。每次重新启动程序默认关闭；在同一次运行中，选择会保留到切换后的模式。

从项目根目录运行 `Launch_HumanityTrinityRebuild.cmd`。模式菜单下方的 **Allow surprise teacher inspections** 复选框可以点击，也可以按 **T** 切换。直接进入漫游或捉迷藏时，也能按 **T** 启用，左下角会显示 ON / OFF。已经听到脚步、进入事件后，需要完成本次检查才能再改变选项。模式选择画面、开局记忆/躲藏准备阶段和结束的回合不会触发检查。

## 遇到老师时

1. 门外传来逐渐接近的硬底鞋脚步、钥匙轻响，以及中文声音：“这么晚了，里面还有人吗？我检查一下。”画面同时显示字幕和逃避倒计时。
2. 立即按 **L**。事件期间，这个按键在所有模式中都会同时关闭教室主灯和教学屏幕；重复按不会误开灯。
3. 前往舞台，进入左右斜墙后的任意一个小暗房。靠近门并对准门扇按 **E** 开门，进入后再按 **E** 关好门。不要停在门扇的转动范围内；门遇到人会暂停，必须让它关到位。
4. NPC 会暂停原有寻找/躲藏行为，走向暗房并关门。玩家和所有参与的 NPC 都需要躲好；站在教室里、只蹲在家具后，不能躲过这次检查。
5. 老师打开教室中间那扇外门，在门口停下检查。走廊灯光从实际门洞照入。保持主灯、教学屏关闭，留在关门的暗房内。
6. 等待老师说话、关门，脚步声远去。HUD 显示离开后才能出来。在捉迷藏中，回到舞台前的教室区域、等待 NPC 返回，原来的剩余时间和玩法随后继续。

| 按键 | 老师事件期间的行为 |
|---|---|
| WASD / 鼠标 | 移动、观察、对准暗房门 |
| L | 关闭所有主灯及教学屏幕 |
| E | 操作舞台暗房门；外侧教室门在检查期间由老师控制 |
| Shift | 慢行；逃往暗房时正常行走更快 |
| T / R / Tab | 本次事件完成之前不能切换检查选项、重开回合或切换练习 |
| M | 尚未失败时退出当前玩法并返回模式菜单 |
| Esc | 退出程序 |

老师一旦发现仍亮着的主灯或教学屏，或者发现玩家/NPC 尚未进暗房并关好门，本次游戏失败。画面显示失败原因，播放老师发现人的声音，约 **8 秒**后退出程序。失败画面不能用 M、R 或 T 绕过。检查期间开灯、开暗房门同样会暴露。

## 时间与原模式衔接

当前默认配置为：启用后约 **35–60 秒**安排首次检查；每次警告约 **24 秒**，开门约 **1.6 秒**，在门口检查 **6 秒**，离开约 **6 秒**。一次成功事件结束后，约 **45–90 秒**再次安排。菜单或准备阶段到期的检查会等待进入可游玩阶段，不会提前开始。时间是原型的可调参数。

捉迷藏的回合倒计时、抓捕和普通 NPC 听觉在事件期间暂停。原有全黑遮罩临时撤下，便于看见门、走廊光线和老师；“你躲藏”模式的舞台临时栏杆也会移开。离开检查后，必须先回到教室区域，才会恢复正常搜索和栏杆；明亮练习恢复主灯，黑暗回合继续保持关灯。漫游在检查后保持玩家主动关闭的照明状态，可以自行按 L 重新开灯。

## 场景、声音与可编辑来源

三扇教室外门默认关闭，漫游中可以靠近按 **E** 操作。门外新增连续走廊、地面、墙面、顶面、灯具和标识。巡查老师是原创风格化人物，穿深色西装外套、衬衫和领带，戴眼镜及工作证，包含分部件的迈步和转头动作。

声音由离线中文语音和程序生成音效组成，含脚步、钥匙、警告、离开和发现三句台词。空间衰减和遮挡滤波让声音从门外传来，提供方向提示；HUD 字幕也会同步提供必要信息。

| 内容 | 可编辑来源 |
|---|---|
| 走廊及外门几何 | `Tools/Blender/patrol_environment.py`、主 Blender 生成器 |
| 老师模型 | `Assets/Teacher/Trinity_Teacher.blend`、`Tools/Blender/build_teacher.py` |
| 中文台词与声音 | `Assets/Audio/Teacher/dialogue.json`、`Tools/Audio/generate_teacher_audio.ps1`、`Tools/Audio/synthesize_teacher_effects.py` |
| 检查时序、发现规则 | `UnrealProject/Source/HumanityTrinityRebuild/HumanityTrinityRebuildTeacherPatrol.h/.cpp` |
| NPC 紧急藏身路线 | `UnrealProject/Source/HumanityTrinityRebuild/HumanityTrinityRebuildHiderEmergency.cpp` |
| 门和走廊灯光 | `UnrealProject/Source/HumanityTrinityRebuild/HumanityTrinityRebuildCorridor.h/.cpp` |

走廊尺寸、照明、老师外形、台词、检查习惯和时间安排为游戏创作；它们不表示已经考证了真实场所的走廊或某位老师。当前是明确的藏身区域和门状态规则，尚未模拟老师走入教室逐桌搜索。

修改后需要重新构建 C++；更改 Blender 几何或声音时还需要重新导出、导入对应 Unreal 资源。自动检查入口是 `Tools/Unreal/validate_teacher_patrol.ps1`。实际验证结果应以相应构建的日志和截图记录为准。
